# Islands VA

B2B virtual-assistant staffing platform: public site, client and VA portal, agency back office. Next.js 16 · Supabase · Vercel.

## Start

```bash
npm ci
npm run dev   # http://localhost:3000
```

Copy the keys listed in `.env` into `.env.local` with real values first (`docs/operations.md`).
